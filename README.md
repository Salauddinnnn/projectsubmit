# 🎓 Project Submission Management System

A modern **Project Submission Management System** built using **HTML, CSS, and JavaScript**. This project is designed to simplify the process of submitting, managing, and reviewing student projects through a clean and user-friendly interface.

---

## 🚀 Features

* 👨‍🎓 Student Project Submission
* 📂 Project Upload Interface
* 📋 Project Details Management
* 📊 Interactive Dashboard
* 🔍 Search & Filter Projects
* ⏳ Submission Status Tracking
* ⭐ Faculty Feedback & Marks
* 📱 Fully Responsive Design
* 🎨 Modern UI/UX
* ⚡ Fast and Lightweight

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage
